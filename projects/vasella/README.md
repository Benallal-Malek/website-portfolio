# Vasella storefront demo

An English-language demo of the Vasella artisan vase shop. It runs on HTML, CSS, and JavaScript.

Open **index.html** in a browser, or [view the live demo](https://benallal-malek.github.io/website-portfolio/projects/vasella/).

The demo includes a searchable catalog, collection filters, price sorting, product details, favorites, a cart, and a simulated checkout. The cart and favorites are stored in the browser. The checkout and newsletter form demonstrate the interface.

Product data lives in the **demo-products** JSON block in **index.html**. Catalog and cart interactions are in **assets/js/demo.js**. Shared storefront interactions are in **assets/js/storefront.js**.

[WordPress theme source](https://github.com/Benallal-Malek/vasella-woocommerce-theme)
