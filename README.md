# Website Portfolio

Eight English-language website demos by [Benallal Malek](https://github.com/Benallal-Malek). Each project has its own page, styles, and assets and runs without a build step.

| Project | What it shows | Source |
| --- | --- | --- |
| Art Remont | Interior renovation landing page with project galleries and an estimate form | [Files](projects/art-remont/) |
| BloomFi | Investment landing page with service and portfolio sections | [Files](projects/bloomfy/) |
| BuildPro | Construction company website with services and an inquiry form | [Files](projects/buildpro/) |
| CarHive | Auto repair and detailing website with service cards and animated counters | [Files](projects/carhive/) |
| Cars | Premium car rental catalog with brand filters and a booking form | [Files](projects/cars/) |
| Fite Lite | Fitness studio landing page with programs and a testimonials carousel | [Files](projects/fite-lite/) |
| Shopkart | Headphone catalog with search, sorting, filters, and favorites | [Files](projects/head-phones/) |
| Inner Balance | Therapist landing page with service descriptions and a consultation form | [Files](projects/iner-balance/) |

## Run locally

From the repository root, run <code>python3 -m http.server 8000</code> and open [localhost:8000](http://localhost:8000/).

The forms simulate submissions in the browser. The Cars catalog uses the original remote photo URLs and displays a local placeholder if a photo fails to load.
