## Run locally

From the repository root, run <code>python3 -m http.server 8000</code> and open [localhost:8000](http://localhost:8000/).

The forms simulate submissions in the browser. The Cars catalog uses the original remote photo URLs and displays a local placeholder if a photo fails to load.
